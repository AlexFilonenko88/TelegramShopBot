## Быстрый вход в код

1. `main.py` — сборка диспетчера и порядок middleware.
2. `bot/handlers/__init__.py` — порядок подключения роутеров (это часть логики).
3. `bot/middlewares/db_retriever.py` — что и под какими именами попадает в
   контекст обработчика.
4. `bot/services/payment_service.py` —-docstring с полным flow оплаты.
5. `bot/keyboards/callback_data.py` — формат всех inline-кнопок.

## Главные инварианты

- Хендлеры не пишут SQL и не импортируют `sqlalchemy`.
- Сервисы не знают про классы Telegram (`Message`, `CallbackQuery`).
- Деньги — только целые копейки; форматирование в `bot/services/money.py`.
- Смена статуса заказа — атомарный `UPDATE ... WHERE status IN (...)`.
- `products.file_url` не покидает сервисный слой без проверки покупки.
- Схема БД меняется только миграциями Alembic; `config.py` не правится.
